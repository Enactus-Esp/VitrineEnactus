## ✨ À propos

Cette application est un site web statique réalisé avec React, Vite et Tailwind CSS. Elle met en valeur :

- les actualités du mouvement
- les projets portés par l'équipe
- les impacts sociaux et environnementaux
- un design responsive et fluide

## 🧩 Technologies utilisées

- React 18
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion
- React Router DOM
- React Helmet Async

## 📁 Structure du projet

- `src/App.tsx` — point d’entrée de l’application
- `src/pages/` — pages principales (Accueil, Projets, Actualités, Contact, etc.)
- `src/components/` — composants UI réutilisables
- `src/data/` — contenu statique du site (projets, actualités, à propos)
- `public/` — ressources publiques

## ▶️ Lancer le projet localement

1. Installer les dépendances :

```bash
npm install
```

2. Démarrer le serveur de développement :

```bash
npm run dev
```

3. Ouvrir l’URL affichée dans le terminal.

## ✅ Commandes utiles

- `npm run dev` — lance l’application en mode développement
- `npm run build` — construit le site pour la production
- `npm run preview` — prévisualise la version buildée
- `npm run lint` — analyse le code avec ESLint
